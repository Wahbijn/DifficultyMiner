# 🎮 Game Difficulty Predictor from Reviews

## 📌 Project Title
DifficultyMiner : Game Difficulty Predictor from Player Reviews 

---

## 📖 Project Description
This project aims to build a Machine Learning system that predicts the **difficulty level of a video game** based only on player reviews.  
The model analyzes textual feedback collected through **web scraping** 

The final system outputs a **difficulty score and difficulty class** for each game.

---

## 🎯 Objectives
- Collect real game reviews using web scraping
- Clean and preprocess textual data
- Extract difficulty-related linguistic features
- Train ML models for difficulty prediction
- Evaluate prediction performance
- Provide a reproducible ML pipeline

---

## 🌐 Data Collection Method
Data is collected using **Web Scraping** from public game review platforms.

Collected fields include:
- Review text
- Recommendation status
- Playtime (if available)
- Review date
- Game identifier

Scraping is performed for **educational purposes only** with rate limiting and structured parsing.

---

## 🧠 Methods & Technologies
- FastAPI
- Web Scraping (Requests / BeautifulSoup / Selenium)
- NLP preprocessing
- Feature Engineering
- Machine Learning models
- Model evaluation metrics
